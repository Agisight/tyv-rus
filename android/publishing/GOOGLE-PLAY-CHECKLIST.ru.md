# Публикация «Тыва-орус сөстүк» в Google Play

Подготовлено 15 октября 2026 года. Версия 1.0 (код 1), пакет `ru.tyv.sostuk`, Android 7.0+ (minSdk 24), targetSdk 36. Это новое приложение, отдельное от `ru.tuvlin.tyv_rus_android`.

## 1. Создать приложение

В аккаунте Tyva Developer откройте All apps → Create app.

| Поле | Выбор |
| --- | --- |
| App name | Тыва-орус сөстүк |
| Default language | Russian — ru-RU |
| App or game | App |
| Free or paid | Free, если сохраняем бесплатное распространение без покупок |
| Package name | ru.tyv.sostuk; закрепляется при загрузке AAB |
| Developer Program Policies / экспортные декларации | Прочитать и подтвердить от имени владельца аккаунта |

Категория: Books & Reference / «Книги и справочники». Теги: «Словарь», «Справочник», «Изучение языков», только если такие доступны и соответствуют описанию в Console. Контактный email: agisight@gmail.com. Сайт и телефон карточки — необязательные поля, если Console не требует их для вашего аккаунта.

## 2. Подпись нового приложения

Включить Play App Signing. Для нового приложения выбрать создание ключа подписи Google — Use a Google-generated app signing key (название может немного отличаться). Готовый AAB подписан вашим локальным upload key. Старый ключ приложения 2015 года для этого пакета не нужен.

`new-upload-key.jks` и `signing.properties` сохранить отдельно в надёжной резервной копии. Не загружать их в карточку, репозиторий или этот комплект. В дальнейшем новые AAB подписывать тем же upload key; Google подписывает распространяемые APK своим app signing key.

## 3. Карточка магазина

Grow users → Store presence → Main store listing. Вставить содержимое файлов из `listing/ru-RU/` в соответствующие поля. Название — до 30 символов, краткое описание — до 80, полное — до 4000.

Загрузить `graphics/icon-512.png` в App icon и `graphics/feature-graphic-1024x500.png` в Feature graphic. В Phone screenshots добавить семь PNG из `phone-screenshots/` по порядку номеров. Дополнительные планшетные экраны из `tablet-screenshots/` можно использовать в соответствующем разделе больших экранов. Видео необязательно. Описания изображений для доступности находятся в `asset-captions.json`.

Иконка магазина — векторная версия прежнего образа с флагами; иконка установленного приложения остаётся прежней. Обложка использует цвета нового интерфейса. На телефонных снимках короткий заголовок занимает верхнюю часть изображения; под ним целиком показан реальный экран версии 1.0. Интерфейс не дорисовывался. Оригиналы без оформления сохранены отдельно. Планшетные снимки — без дополнительных надписей.

### Маркировка AI asset declaration

Для подготовленного комплекта рекомендуем выбрать **Label assets as created or edited using AI**. На следующем шаге отметить обложку, новую иконку из комплекта и семь оформленных телефонных скриншотов: их графику, заголовки и композицию подготовил ИИ. Планшетные снимки и исходные телефонные PNG без оформления — прямые снимки приложения; для них отметка не предлагается. Если используете прежнюю иконку вместо новой, оценивать именно загруженный файл.

Это рекомендация для прозрачности: [справка Google](https://support.google.com/googleplay/android-developer/answer/17262077?hl=ru) предусматривает отдельный выбор для каждого материала, но отдельно не разъясняет оформление через созданный ИИ код SVG/HTML.

## 4. Политика конфиденциальности

Файл `privacy/index.html` готов к размещению на общедоступном HTTPS-сайте. Сначала опубликовать его и проверить ссылку в приватном окне без авторизации, затем вставить URL в App content → Privacy policy. Локальный путь, ссылка на редактируемый документ и адрес репозитория с исходным HTML не заменяют публичную страницу. В приложении политика уже доступна через «Инфо».

Публичного URL в комплекте пока нет. Не вводить предполагаемый адрес GitHub Pages, пока сайт действительно не включён и страница не проверена. Возможный способ размещения: GitHub Pages этого репозитория или ваш существующий сайт.

## 5. App access и реклама

App access: All functionality is available without any access restrictions. Логин, пароль и тестовый аккаунт не нужны.

Ads: No, my app does not contain ads. В коде нет рекламных модулей.

## 6. Data safety

Для этой сборки: Is any required user data collected or shared? → No. Поиск и вопросы обрабатываются локально, аналитики и сетевых SDK нет. «Поделиться» и открытие внешнего Переводчика — явные действия пользователя с пояснением, что текст перейдёт во внешний сервис; это учитывается в исключении Google для ожидаемых действий пользователя. Политика отдельно описывает эти действия и обращения по email.

Создание аккаунта не поддерживается. Поля удаления аккаунта, типов собираемых данных, целей сбора и защиты передаваемых разработчику данных обычно не появляются при таком ответе. Если Console задаёт дополнительные вопросы, отвечать по их буквальному смыслу; не заявлять независимый аудит безопасности или сбор данных, которого нет. Обновить декларацию, если появятся сервер, аналитика, реклама или новые SDK.

## 7. Target audience and content

Выбрать согласованные возрастные группы: 13–15, 16–17, 18 and over. Группы до 13 лет не выбирать. Не включать ограничение «только взрослые», иначе оно противоречит выбранной аудитории. Не отмечать участие в программе приложений для маленьких детей. Статус аудитории и возрастной рейтинг — разные поля.

## 8. Content rating / IARC

Указать agisight@gmail.com и категорию приложения, соответствующую справочнику (обычно All Other App Types). В приложении нет чата между пользователями, пользовательских публикаций, покупок, азартных игр, геолокации или рекламных объявлений. Раздел «Спросить» отвечает из локального словаря, а не общается с другим человеком.

Анкету о содержимом необходимо пройти по фактическим словарным статьям: не ставить автоматически «нет» во всех пунктах. В базе есть справочные упоминания убийства, алкоголя и курения (например, статьи өлүрүүшкүн, арага, таакпылаар). Учитывать точную формулировку вопросов, контекст и частоту; справочная лексика сама по себе не означает пропаганду или изображение сцен. Итоговый рейтинг выставляет IARC, заранее обещать 3+ или 13+ нельзя. Если вопрос вызывает сомнение, сохранить черновик и разобрать его текст отдельно.

## 9. Остальные декларации App content

Если Console их показывает: News app → No; Government app → No; Financial features → приложение не предоставляет финансовых функций; Health apps → приложение не предоставляет медицинских функций; COVID-19 → не относится. Словарное значение медицинского или финансового слова не является функцией медицинского/финансового сервиса. Permissions / sensitive access: специальные разрешения не используются. Публикация кода в GitHub не делает приложение государственным.

## 10. Цена, страны и устройства

Pricing: Free, если выбран бесплатный выпуск. Countries/regions: включить те страны, где вы хотите распространение; автоматически выбирать за владельца аккаунта все страны не требуется. Локализация карточки по умолчанию русская. Не включать Android TV, Wear OS, Automotive и XR как отдельные платформы: для них эта сборка не подготовлена.

## 11. Внутренний тест

Testing → Internal testing → Create release. Загрузить `sostuk-1.0-api36.aab`, дождаться обработки. Ожидаемые значения: пакет ru.tyv.sostuk, версия 1.0, код 1, target SDK 36. В поле release name можно написать 1.0. Вставить текст `listing/ru-RU/release-notes.txt` в русскую секцию release notes. Если поле предлагает теги, использовать `<ru-RU>` и `</ru-RU>` вокруг текста; сами теги не нужны в файле.

Добавить собственный Google-аккаунт в тестировщики. Сохранить и подтвердить внутренний выпуск, открыть opt-in ссылку под этим аккаунтом и установить из Google Play. Проверить холодный запуск, поиск «буян» и «медведь», статью «таваар», примеры, опечатку «медвдь», «Поделиться», закрытие «Инфо» и работу в авиарежиме. Внешний Переводчик в авиарежиме недоступен — это ожидаемо.

## 12. Production

После проверки карточки, публичной политики, деклараций, рейтинга и тестовой установки: Production → Create release / Promote release. Использовать тот же проверенный AAB из библиотеки и проверить предупреждения Console. Сначала сохранить черновик и просмотреть итог. Send for review и публикацию подтверждает владелец аккаунта. В этом комплекте ничего не отправлено на проверку и не опубликовано.

Если Console потребует закрытого тестирования или иных условий доступа к Production, выполнить показанное требование для конкретного аккаунта; число тестировщиков не назначается по предположению.

После доступности нового приложения можно отдельно обновить описание старого со ссылкой на `https://play.google.com/store/apps/details?id=ru.tyv.sostuk`. До выхода нового приложения эта ссылка может не открываться. Автоматического обновления старой установки и переноса отзывов не будет. Снимать старое приложение с публикации стоит только после проверки перехода.

## Проверка комплекта

См. `validation.json` и `SHA256SUMS.txt`. AAB проверен по подписи, пакету и версии; последняя проверка этого же кода приложения до смены номера прошла 34 инструментальных теста. Скриншоты сняты с неопубликованной сборки 2.1.5; интерфейс первого выпуска 1.0 остался тем же. Изменены только номер версии и код сборки. Ключей и паролей в архиве нет.
